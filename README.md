A deterministic program that writes one line — the funniest one-line resignation letter it can, from a ventriloquist whose dummy has been promoted twice while he has not been promoted once — to `/output/entry.txt`. The line: a ventriloquist resigns because his dummy keeps getting promoted over him.

## Run it

```sh
python3 main.py
```

The program reads `$MAKEFUN_OUTPUT_DIR` (falling back to `/output`), validates the line against the gate (UTF-8, 1–140 characters, single line, not whitespace-only, no trailing newline), writes it atomically via a mkstemp temp file with an anti-partial-write loop and fsync, and verifies the written bytes by reading them back.
